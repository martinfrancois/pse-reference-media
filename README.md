# pse-reference-media

Short, silent excerpts of openly licensed video. Each clip comes with its licence, attribution,
source and an exact technical description. The clips are ordinary footage that a checker for
photosensitive epilepsy guidelines (Ofcom, ITU-R BT.1702, WCAG 2.3.1 and similar) should pass:
fast cuts, pans, grain, water, foliage, text, fades and a range of technical formats.

The repository holds no flashing material and no copyrighted footage.
